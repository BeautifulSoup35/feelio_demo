# Feelio Wireframe

이 문서는 현재 React 화면 구조를 기준으로 추출한 와이어프레임입니다.
일부 소스 파일의 한글 문자열은 인코딩이 깨져 있어, 실제 UI 문구는 코드 구조와 컴포넌트 역할을 기준으로 의미를 복원했습니다.

## 전체 앱 구조

- 로그인 전: `LoginPage`
- 로그인 후: `AppShell`
- 데스크톱: 좌측 `Sidebar` + 중앙 `mainSurface`
- 모바일: 중앙 단일 컬럼 + 하단 `BottomNav`
- 공통 배경: aurora 배경 3개, 감정 마스코트
- 공통 프로필 진입: 홈 상단 프로필 버튼 또는 사이드바 프로필 영역

```text
[로그인 전]
┌────────────────────────────────────┐
│ LoginPage                          │
│ ├─ 브랜드/서비스 소개              │
│ └─ OAuth 로그인 카드               │
└────────────────────────────────────┘

[로그인 후 - 데스크톱]
┌──────────────┬─────────────────────┐
│ Sidebar      │ Main Surface        │
│ - Logo       │ - Home              │
│ - Home       │ - Calendar          │
│ - Calendar   │ - Content           │
│ - Content    │                     │
│ - Profile    │                     │
└──────────────┴─────────────────────┘

[로그인 후 - 모바일]
┌────────────────────┐
│ Main Surface       │
│                    │
│                    │
├────────────────────┤
│ Bottom Navigation  │
└────────────────────┘
```

## 1. 로그인 화면

Source: `src/components/auth/LoginPage.jsx`

목적:
- Feelio의 핵심 가치 소개
- OAuth 계정으로 앱 진입

구성:
- 배경 aurora 효과
- 좌측/상단: 로고, 헤드라인, 서비스 설명
- 우측/하단: 로그인 카드
- 로그인 수단: Google, Kakao, Apple
- 현재는 mock 로그인으로 동작

```text
┌────────────────────────────────────┐
│ Logo                               │
│                                    │
│ [서비스 헤드라인]                  │
│ [서비스 설명 문장]                 │
│                                    │
│ ┌────────────────────────────────┐ │
│ │ OAuth 로그인                   │ │
│ │ 소셜 계정으로 시작             │ │
│ │                                │ │
│ │ [Google로 계속하기]            │ │
│ │ [Kakao로 계속하기]             │ │
│ │ [Apple로 계속하기]             │ │
│ │                                │ │
│ │ mock 로그인 안내               │ │
│ └────────────────────────────────┘ │
└────────────────────────────────────┘
```

주요 액션:
- 소셜 로그인 버튼 클릭 → `actions.login(provider)` 실행 → 홈 화면 진입

## 2. 홈 화면

Source:
- `src/pages/HomePage.jsx`
- `src/components/home/EmotionExpenseCard.jsx`
- `src/components/home/MoodRidge.jsx`

목적:
- 오늘의 감정 소비를 빠르게 기록
- 이번 달 감정 소비 흐름과 목표 상태를 한눈에 확인

구성:
- 상단 리드: 날짜, 사용자 인사말, 프로필 버튼
- 메인 영역:
  - 감정 소비 입력 카드
  - 이번 달 마음 능선 카드
- 보조 영역:
  - 이번 달 감정 소비 누수율
  - AI 소비 신호
  - 주요 목표 진행률

```text
┌────────────────────────────────────┐
│ 날짜                               │
│ 안녕, 사용자명              [프로필] │
├────────────────────────────────────┤
│ 오늘 쓴 돈, 어떤 기분이었어?       │
│ [지출/수입 토글]          [저장]    │
│                                    │
│ ┌────────────────────────────────┐ │
│ │ 메모 입력                      │ │
│ │ 금액 입력                      │ │
│ │                                │ │
│ │ [카테고리] [감정] [상황]        │ │
│ └────────────────────────────────┘ │
│                                    │
│ 선택한 태그 그룹의 후보 칩 목록    │
├────────────────────────────────────┤
│ 이번 달 마음 능선                  │
│ [감정 분포 시각화]                 │
├────────────────────────────────────┤
│ 이번 달 감정 소비 누수율           │
│ [퍼센트] [진행 바] [설명]          │
├────────────────────────────────────┤
│ AI 소비 신호                       │
│ [AI 코멘트] [감정 Blob]            │
├────────────────────────────────────┤
│ 목표 카드                          │
│ [목표명] [진행률] [진행 바]        │
└────────────────────────────────────┘
```

감정 소비 입력 카드 상세:

```text
┌────────────────────────────────────┐
│ 제목/설명                          │
│ [지출] [수입]              [저장]   │
├────────────────────────────────────┤
│ 메모                               │
│ [memo input]                       │
│                                    │
│ 금액                               │
│ ₩ [amount input]                   │
│                                    │
│ [#카테고리] [#감정] [#상황]         │
├────────────────────────────────────┤
│ 선택된 그룹이 있을 때              │
│ [후보 태그] [후보 태그] [후보 태그] │
└────────────────────────────────────┘
```

주요 상태:
- `transactionType`: `EXPENSE` 또는 `INCOME`
- `amount`: 금액 입력값
- `memo`: 메모 입력값
- `selectedCategoryId`: 소비 분류
- `selectedEmotionId`: 감정
- `selectedSituationId`: 상황
- `activePicker`: 현재 펼쳐진 태그 그룹
- `saveState`: 저장 전/저장 완료 상태

주요 액션:
- 지출/수입 토글 변경
- 메모/금액 입력
- 카테고리/감정/상황 태그 선택
- 저장 클릭 → `onAddTransaction` 호출
- 프로필 버튼 클릭 → `ProfileModal` 열림

모바일 레이아웃 메모:
- 홈 입력 카드는 모바일에서 1열 구조
- 금액 입력과 태그 칩은 부모 폭 안에서 줄바꿈
- 하단 탭바가 고정되어 있으므로 본문 하단 여백 필요

## 3. 캘린더 화면

Source:
- `src/pages/CalendarPage.jsx`
- `src/components/calendar/CalendarRecordForm.jsx`

목적:
- 날짜별 감정 소비 흐름을 캘린더로 확인
- 특정 날짜의 거래 기록을 보고 추가/삭제

구성:
- 월 헤더: 연/월, 설명, 이전/다음 월 버튼
- 감정 범례
- 월간 감정 캘린더
- 선택 날짜 패널
- 기록 추가 모달

```text
┌────────────────────────────────────┐
│ 2026년 6월                  [<][>] │
│ 월간 감정 소비 설명                 │
│ [범례: 외로움/설렘/불안/평온/분노] │
├────────────────────────────────────┤
│ 월간 캘린더                         │
│ ┌──┬──┬──┬──┬──┬──┬──┐             │
│ │일│월│화│수│목│금│토│             │
│ ├──┼──┼──┼──┼──┼──┼──┤             │
│ │  │  │  │  │  │  │  │             │
│ │ 감정 색상/선택/오늘 표시         │
│ └──┴──┴──┴──┴──┴──┴──┘             │
├────────────────────────────────────┤
│ 선택한 날짜                         │
│ [날짜 제목]                   [+]  │
│ [대표 감정 Pill]                    │
│ 오늘의 소비 n건 · 합계 금액         │
│                                    │
│ 기록 리스트                         │
│ [아이콘] 제목/메모             금액 │
│ [아이콘] 제목/메모             금액 │
└────────────────────────────────────┘
```

기록 추가 모달:

```text
┌────────────────────────────────────┐
│ 선택 날짜 기록 추가            [X] │
│ 설명                               │
├────────────────────────────────────┤
│ [지출] [수입]      거래 유형        │
├────────────────────────────────────┤
│ 메모 입력              금액 입력    │
│                                    │
│ [#카테고리] [#감정] [#상황]         │
├────────────────────────────────────┤
│ 선택한 태그 그룹의 후보 목록        │
│ [태그] [태그] [태그]                │
├────────────────────────────────────┤
│ [기록 저장하기]                     │
└────────────────────────────────────┘
```

주요 상태:
- `selectedDate`: 현재 선택 날짜
- `visibleMonth`: 현재 보고 있는 월
- `isAdding`: 기록 추가 모달 열림 여부
- `activeRecordId`: 삭제 액션이 열린 기록 ID

주요 액션:
- 이전/다음 월 이동
- 날짜 선택
- `+` 클릭 → 기록 추가 모달 열림
- 모달에서 기록 저장 → `onAddTransaction`
- 기록 행 클릭 → 삭제 버튼 노출
- 삭제 버튼 클릭 → `onRemoveTransaction`

## 설계 메모

- 앱의 핵심 루프는 `기록 → 감정 태그 → 월간 흐름 확인 → 인사이트 확인`입니다.
- 홈 화면은 기록 입력을 최우선으로 배치하고, 캘린더는 날짜별 회고, 콘텐츠는 분석/추천 영역으로 역할이 분리되어 있습니다.
- 현재 문자열 인코딩이 깨진 파일이 있어, 최종 발표/문서 제출 전에는 UI 문구를 UTF-8 기준으로 정리하는 작업이 필요합니다.
